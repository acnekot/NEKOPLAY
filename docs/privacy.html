NEKOPLAY 隐私政策

生效日期：2026 年 11 月 27 日 · 适用于 NEKOPLAY 全部版本（Android / Windows / macOS / Linux / iOS，含 Microsoft Store 版）
简体中文English日本語

概述

NEKOPLAY 是一款本地优先的音乐播放器。开发者不运营任何收集用户数据的服务器，应用不包含统计分析、广告或遥测组件，也不会把你的个人信息发送给开发者。

保存在你设备上的数据

以下数据只保存在你的设备上（Windows：%APPDATA%\NEKOPLAY；macOS / Linux：~/.nekoplay；手机端为应用私有目录），卸载应用或删除该目录即可清除：

  • 应用设置、主题与界面偏好；
  • 播放队列、播放历史、收听统计、喜欢的歌曲与歌单缓存；
  • 你安装的插件及其配置；
  • 你在插件中登录第三方服务后产生的登录凭据（如 Cookie / Token），仅供对应插件访问该服务时使用；
  • 音频缓存与离线下载的文件。

应用会发起的网络连接

  • 检查更新（官网 / GitHub 直装版）：访问 GitHub 获取最新版本信息。Microsoft Store 版由商店负责更新，不进行此连接。
  • 插件订阅：你添加的插件订阅地址（如 GitHub 及其 jsDelivr 镜像）用于下载插件列表与插件文件。
  • 插件：插件由你自行选择安装，插件会按其功能连接第三方服务（例如获取曲目信息、歌词、封面或音频）。这些请求直接从你的设备发往该服务，开发者无法看到其内容。第三方服务如何处理你的数据，以该服务自己的隐私政策和条款为准。插件需要声明网络权限，访问本机或局域网地址需要额外声明。
  • WebDAV（可选）：如果你配置了 WebDAV 服务器，应用会连接该服务器读取音乐或备份 / 恢复你的设置与数据。
  • Discord 状态（可选，仅桌面端）：开启后，应用会通过你电脑上的 Discord 客户端展示正在播放的歌曲信息。

数据共享

开发者不会出售、出租或共享你的个人信息。除上面列出的、由你主动开启或安装的功能外，应用不会把你的数据发送给任何第三方。

应用商店提供的数据

如果你通过应用商店（如 Microsoft Store）安装，商店可能会按其自身政策向开发者提供汇总的下载统计和崩溃报告。开发者仅用这些信息修复问题和改进应用；其中如包含个人信息，会在 30 天内删除。

备份与导出

你可以在 设置 → 备份 中导出数据，并可选择用密码加密。导出文件由你自行保管。

儿童

本应用不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

政策变更与联系方式

本政策如有变更，会更新此页面并修改生效日期。有任何疑问，请在 GitHub Issues 联系我们。

NEKOPLAY Privacy Policy (English)

Effective date: November 27, 2026. Applies to all editions of NEKOPLAY, including the Microsoft Store edition.

NEKOPLAY is a local-first music player. The developer does not operate any server that collects user data. The app contains no analytics, advertising or telemetry, and does not send your personal information to the developer.

Data stored on your device: settings, play queue and history, listening statistics, liked songs and playlist cache, installed plugins and their settings, sign-in credentials (cookies / tokens) created when you sign in to a third-party service through a plugin (used only by that plugin), and audio cache / downloads. This data stays on your device (Windows: %APPDATA%\NEKOPLAY; macOS / Linux: ~/.nekoplay; app-private storage on mobile) and is removed when you uninstall the app or delete that folder.

Network connections: update checks against GitHub (direct-download editions only; the Microsoft Store edition is updated by the Store); plugin subscription URLs you add (such as GitHub and its jsDelivr mirror); plugins you choose to install, which connect directly from your device to third-party services according to their function (the developer cannot see this traffic, and each service's own privacy policy applies); an optional WebDAV server you configure; and optional Discord status on desktop, which uses the Discord client on your computer.

Sharing: the developer does not sell, rent or share your personal information. App stores may give the developer aggregated download statistics and crash reports under their own policies; these are used only to fix bugs, and any personal information in them is deleted within 30 days.

Children: the app is not directed at children under 13. Changes and contact: changes are posted on this page with a new effective date. Contact us via GitHub Issues.

施行日：2026 年 11 月 27 日。Microsoft Store 版を含む NEKOPLAY の全エディションに適用されます。

NEKOPLAY はローカル優先の音楽プレーヤーです。開発者はユーザーデータを収集するサーバーを運営しておらず、アプリには分析・広告・テレメトリー機能は含まれず、個人情報を開発者に送信することはありません。

端末に保存されるデータ：設定、再生キューと履歴、再生統計、お気に入りとプレイリストのキャッシュ、インストールしたプラグインとその設定、プラグイン経由で外部サービスにログインした際の認証情報（Cookie / トークン。該当プラグインのみが使用）、音声キャッシュとダウンロード。これらは端末内にのみ保存され、アンインストールまたは保存フォルダの削除で消去されます。

通信：GitHub への更新確認（直接配布版のみ。Microsoft Store 版はストアが更新）、追加したプラグイン購読 URL、ユーザーが選んでインストールしたプラグインによる外部サービスへの直接通信（開発者は内容を確認できず、各サービスのポリシーが適用されます）、任意で設定した WebDAV サーバー、デスクトップ版の任意機能「Discord ステータス」。

共有：開発者は個人情報を販売・貸与・共有しません。ストアから提供される集計統計やクラッシュレポートは不具合修正のみに使用し、個人情報が含まれる場合は 30 日以内に削除します。お問い合わせは GitHub Issues へ。
