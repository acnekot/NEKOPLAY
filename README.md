# NEKOPLAY · 本地音乐播放器

BenchLab 风格的本地音乐播放器：队列、歌词（原文 / 罗马音 / 翻译）、真实频谱、内嵌封面。同一套前端既能用浏览器直接打开，也能打包成 Tauri 桌面应用。

> 早期规划名：Synceko；当前原型名：NEKOPLAY。

## 项目计划

- [x] 基础听歌功能（本地导入、队列、歌词、频谱、内嵌封面）
- [ ] 网盘听歌上传
- [ ] 一起听功能
- [x] 主题功能（经典 / 玻璃 / 大字 / 数字 / 初版）
- [ ] 登录音乐平台

UI 参考 [Hydrogen-Music](https://github.com/Kaidesuyo/Hydrogen-Music)；一起听功能参考 [Music Party](https://github.com/EveElseIf/MusicParty)。

## 运行

### 1. 浏览器原型

直接双击 `index.html`（Chrome / Edge / Firefox），不需要服务器。

- 桌面：窗口宽度 ≥ 1000px。
- 手机：窗口宽度 < 1000px，推荐用 DevTools 切到 390×844 查看。

### 2. Tauri 桌面版

前置：Node 18+、Rust（MSVC toolchain）、Visual Studio Build Tools（C++）、WebView2（Win10/11 自带）。

```bash
npm install          # 只装 Tauri CLI
npm run dev          # 开发模式
npm run build:exe    # 只生成 exe
npm run build        # 生成 exe + NSIS 安装包
```

产物：

- `src-tauri/target/release/nekoplay.exe`
- `src-tauri/target/release/bundle/nsis/NEKOPLAY_0.1.0_x64-setup.exe`

`src-tauri` 只加载 `dist/`，`npm run sync` 会把根目录的 `index.html / style.css / app.js` 复制过去；`dev` 与 `build` 已包含这一步。改完前端重新 build 即可。

桌面版细节：

- 无边框窗口（`decorations: false`）：顶栏左侧空白 / 品牌区可拖动窗口，双击顶栏最大化；右上角是 48×72 的自绘最小化 / 最大化 / 关闭按钮，关闭悬停变红，浏览器里自动隐藏。
- 顶栏采用导出的 TopBar 设计：毛玻璃背景、四角标搜索、头像菜单（设置 / 导入音乐 / 退出应用），窗口按钮与内容之间用 1px 分隔线。
- 启动时按主屏可用区域的 88% 居中打开（最大 1440×900，最小 1000×700），避免高 DPI 下超出屏幕。
- 已给 WebView2 设置 `--autoplay-policy=no-user-gesture-required`，导入音频后可直接播放。
- 文件选择、Blob 播放、Web Audio 频谱、localStorage 在 WebView2 中均可正常工作。
- 安装包未签名，Windows 可能弹出 SmartScreen 提示（「更多信息 → 仍要运行」）。

## 已实现

**版面（SPEC 1–3）**
- 顶栏 72px：品牌 + 跳动音柱、四项导航（主页 / 正在播放 / 曲库 / 播放列表）、四角标搜索框（聚焦从 240 展开到 340，右侧提示 ESC 清空）、头像菜单（设置 / 导入音乐 / 退出应用），顶栏为半透明毛玻璃。
- 左栏 440：CSS 几何封面（4 款按序号取）、40px 曲名、艺人、等宽元信息、`NEXT · 下一首` 块。
- 右栏：`队列 / 歌词` 标签、等宽计数、64px 队列行、当前行浅蓝底 + 3px 主色竖条、每行小音柱（当前行跳动）、点击切歌、悬停右移。
- 吸底播放栏 109px + 3px 顶线：迷你封面、上/下一首、136×56 主按钮、进度、顺序/随机/单曲、音量。滚动时保持可见。
- 桌面是固定应用壳：整个页面不滚动，左栏（封面 / 曲名 / NEXT）始终不动，右侧队列 / 曲库 / 歌词 / 主页在各自区域内滚动；窗口变矮时左栏与封面同步收窄，保证信息不被播放栏截断。
- 全页只有一个主色、直角、无卡片阴影（设置面板除外）。

**主页**
- 桌面默认落地页：`一 · 继续播放`（封面 / 进度 / 继续播放 / 打开队列）、`二 · 每日推荐`（当天日期 / 播放按钮 / 3 首）、`三 · 推荐合集`（5 个心情合集）、底部统计条（曲库 / 总时长 / 艺人 / 无损占比）。
- 数据驱动：每日推荐按日期 + 曲库稳定生成，合集与统计随导入实时更新；主页内部滚动，播放栏固定。
- 「继续播放」切换播放/暂停，「打开队列」进入正在播放，「查看全部」进入曲库；每日推荐和合集条目点击直接切歌。

**封面（SPEC 5）**
- 没有内嵌封面时使用四款纯 CSS 封面：黑底蓝圆、主色竖条纹 + 黑方块、白底同心环 + 蓝点、4×4 网格 + 4 个填色格。
- 导入音频时读取真实内嵌封面：MP3（ID3v2.2/2.3/2.4 的 `APIC`/`PIC`）、FLAC（`PICTURE` 元数据块）、M4A/MP4（`covr` 原子），主封面会替换到左侧大图、播放栏迷你封面和手机歌词页迷你封面；没有封面时自动回退到几何图案。

**播放**
- 示例曲目没有音频文件，用计时模拟（按 SPEC 第 2 轮的约定），暂停/切歌/进度/音量/模式全部可用。
- 「上一首」在已播超过 3 秒时回到开头；单曲模式播完重播；随机模式随机下一首。
- 「导入音乐」选择本地音频后追加到队列，曲名取文件名、艺人「本地文件」、时长读 `loadedmetadata`、采样率取 `AudioContext.sampleRate`，并自动播放第一首。

**频谱（SPEC 4）**
- 固定背景层，底边在播放栏上沿，48 根柱、16% 不透明度、200px 高、顶部渐变遮罩。
- 示例曲目用 CSS `eq` 动画模拟；导入真实音频后用 `AnalyserNode`（fftSize 2048、smoothing 0.8）按 30Hz–16kHz 对数刻度驱动柱高。暂停时平滑落到 `scaleY(.06)`。
- 设置面板 8 项全部生效：显示、样式（柱状/细线/镜像）、位置（底部/铺满）、柱数（24/48/96）、速度（0.5×/1×/2×，只影响模拟动画）、透明度 4–45%、高度 80–320px（铺满时置灰）、8 种颜色。
- 写入 `localStorage` 的 `nekoplay.spectrum`，刷新后恢复；「恢复默认」清空。Esc 关闭、焦点进入/返回。

**歌词（SPEC 6）**
- 解析 `[mm:ss.xx]`，忽略 `[ti:]/[ar:]`；同一时间戳连续多行识别为 原文 / 罗马音 / 翻译，两行且第二行含中日文时识别为 原文 + 翻译。
- 示例 `sample.lrc` 挂在第 4 首《Low Tide Index》上；其他曲目显示空状态 + 「导入歌词」。
- 「原文 / 罗马音 / 翻译」多选筛选，至少保留一项，缺数据的项置灰；筛选写入 `nekoplay.lyrics`。
- 当前行三层高亮，其他行只显示原文 + 翻译；点击任意行跳转；播放时当前行滚到列表中间，手动滚动后 4 秒内不自动跟随。

**手机（SPEC 7）**
- 品牌 + 44×44 搜索图标（展开为搜索行）→ 3px 黑线 → `正在播放 / 队列 / 歌词` 三个标签。
- 播放页：封面撑满、30px 曲名、进度（时间在滑块上方左右）、52/60/52 控制行、44 高三等分模式、单行 NEXT。
- 歌词页：48px 迷你封面 + 曲名 + 艺人 + 已播时间、右上角 `LYRICS` 标记（隐藏搜索图标）、36 高筛选标签、当前行前后共 6 行（含罗马音 / 翻译）、底部固定进度 + 控制行。
- 频谱 220px / 16%，不提供设置面板。

**动效与无障碍（SPEC 8、10）**
- 区块依次上浮 + 去模糊（0.7s，间隔 70ms）；播放按钮悬停上浮，次按钮悬停铺浅蓝。
- `prefers-reduced-motion` 下关闭全部动画，频谱柱固定 `scaleY(.3)`。
- 空格播放/暂停（输入框与按钮聚焦时交给浏览器），←/→ 切歌；Tab 焦点为 2px 主色轮廓；标签页 / 分段控件 / 图标按钮带 `role`、`aria-selected`、`aria-pressed`、`aria-label`。

## 主题（设置 → 主题）

「设置」面板顶部新增「主题」，5 套版式即时切换并写入 `nekoplay.theme`（入口：右上角头像 → 设置）：

| 主题 | 说明 |
|---|---|
| 经典（Main） | 默认的 BenchLab 双栏 + 吸底播放栏；每行序号前有跳动小音柱 |
| 玻璃（Glass） | 右侧队列变成磨砂玻璃卡片，播放栏半透明，模式改为图标 + 下划线，音量显示 `VOLUME` + 数值 |
| 大字（BigType） | 大标题 + 右侧封面 + 底部大号已播时间，隐藏队列；播放栏模式在左、控制居中、音量在右 |
| 数字（BigNum） | 超大曲目序号 + 右侧封面 + 底部曲名/时间，隐藏队列；播放栏同大字 |
| 初版（Original） | 报表式大号 04 + 左栏内嵌进度/控制/模式/音量 + 表格队列（波形列 / 表头 / 合计）+ 格式 / 采样率 / 剩余；隐藏底部播放栏 |

主题只作用于桌面（≥1000px）；手机端保持 Main 版式。大字 / 数字主题为了还原设计会隐藏右栏，切回经典即可继续使用队列和歌词；初版隐藏底部播放栏，控制都在左栏。

## 快速试玩

1. 打开后默认是「主页」：点「继续播放 / 暂停」、进度、每日推荐、5 个心情合集和底部统计；「打开队列」进入正在播放。
2. 点右上角「猫」→「导入音乐」选一首本地歌：会切到真实音频，频谱变成真实频谱。再点「歌词」看空状态，点「导入歌词」选一个 `.lrc`。
3. 点右上角「猫」→「设置」：顶部切 经典 / 玻璃 / 大字 / 数字 / 初版；下面继续调频谱，刷新页面验证保留。
4. 点「曲库」「播放列表」看另外两种右栏视图；搜索 `signal` 或乱输 `zzzz` 看筛选与空状态。
5. 把窗口缩到 390 宽：三个标签切换播放页 / 队列 / 歌词，歌词右上角显示 `LYRICS`，当前行前后共 6 行（含罗马音）。

## 存储键

- `nekoplay.theme`：主题。
- `nekoplay.spectrum`：频谱设置。
- `nekoplay.lyrics`：歌词显示层筛选。

## 说明与取舍

- 示例曲目是虚构数据，没有随包音频，所以默认是模拟播放；只有导入本地文件后才出声。
- 内嵌封面支持 MP3 / FLAC / M4A / MP4；OGG（`METADATA_BLOCK_PICTURE`）暂未解析，会回退到 CSS 封面。
- 浏览器里 `AudioContext` 在首次点击播放 / 导入时创建；Tauri 桌面版已关闭自动播放限制。
- 「曲库」「播放列表」在规格里只给了导航入口，这里补成可用的列表视图（曲库 = 全部曲目，播放列表 = 默认列表 + 本地导入）。
- 主页是导出的 Home board；原稿的统计条在播放栏下方，当前壳把统计条放在主页内容末尾、播放栏上方，主页内部滚动。
- 大字 / 数字主题会隐藏右栏，稿子顶部的「队列 / 歌词」入口没有并入（当前 TopBar 结构下换回经典即可查看），后续可加浮动入口。
- 头像菜单里的「退出应用」在浏览器预览只提示；Tauri 里会关闭窗口。账户/登录、网盘上传、一起听仍是计划项。
- 「铺满」解释为频谱从播放栏上沿铺到页面顶部，此时高度设置置灰；高度上限 320px 作用于「底部」模式。
- 字体通过 Google Fonts 加载，离线时回退到系统 Inter / 苹方 / 微软雅黑 / Consolas。
- 已用无头 Chrome 在 1440×900、1000×800 与 390×844 做过交互回归，无控制台报错；桌面是固定壳，主页和右侧列表内部滚动。
